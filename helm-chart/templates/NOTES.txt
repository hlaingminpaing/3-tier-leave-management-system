1. Get the application URL by running these commands:
{{- if .Values.ingress.enabled }}
  Ingress is enabled: https://{{ .Values.ingress.host }}
{{- else if contains "NodePort" .Values.frontend.service.type }}
  export NODE_PORT=$(kubectl get nodes --namespace {{ .Values.global.namespace }} -o jsonpath="{.items[0].status.addresses[?(@.type=='ExternalIP')].address}")
  export NODE_PORT=$(kubectl get services --namespace {{ .Values.global.namespace }} {{ include "leave-management-system.fullname" . }}-frontend -o jsonpath='{.spec.ports[0].nodePort}')
  echo http://$NODE_PORT:{{ .Values.frontend.service.port }}
{{- else if contains "LoadBalancer" .Values.frontend.service.type }}
  NOTE: It may take a few minutes for the LoadBalancer IP to be available.
  You can watch the status of by running:
    kubectl get svc --namespace {{ .Values.global.namespace }} -w {{ include "leave-management-system.fullname" . }}-frontend
{{- else if contains "ClusterIP" .Values.frontend.service.type }}
  Use port-forward to access the service:
    kubectl port-forward -n {{ .Values.global.namespace }} service/{{ include "leave-management-system.fullname" . }}-frontend 8080:80
    Visit: http://localhost:8080
{{- end }}

2. Check the status of deployments:
  kubectl get pods -n {{ .Values.global.namespace }}

3. View logs from components:
  # Backend logs
  kubectl logs -n {{ .Values.global.namespace }} -l component=backend

  # Frontend logs
  kubectl logs -n {{ .Values.global.namespace }} -l component=frontend

  # MySQL logs
  kubectl logs -n {{ .Values.global.namespace }} -l component=mysql

    helm:
      valuesFiles:
      - values.yaml
      - values-prod.yaml

7. Troubleshooting:
  {{- if .Values.ingress.enabled }}
  - Ensure your ACM certificate ARN is set in ingress.annotations
  {{- end }}
  - Check if ingress-alb-controller is installed for ALB ingress
  - Verify MySQL is running before backend connects:
    kubectl get pods -n {{ .Values.global.namespace }} -l component=mysql
